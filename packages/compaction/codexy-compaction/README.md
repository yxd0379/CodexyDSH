# @codexydsh/compaction

Token-meter-driven compaction policy and LLM summarization backend for the DeepSeek Harness.

The policy consumes the product-owned `codexyTokenMeter` so native schemas and required request facts contribute to pressure estimates.

Installed through the product bundles and profiles; DSH remains the unmodified platform dependency.

Exports: `.`, `./service`.

Build and focused behavior tests are run from the repository root. See [product setup](../../README.md) and [component validation](../../README.md#组件清单与验证范围).
