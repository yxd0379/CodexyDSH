# @codexydsh/ui-memory

Provides Session memory status, search and editing controls, refresh, and bounded status polling. It mounts the owned Memory RPC contribution when enabled.

Enable this product plugin instead of the corresponding stock UI plugin. The fixed DSH 0.2.1-alpha.2 connection, Session, locale, layout, and slot services remain the framework providers. Browser entries are discovered through `dsh.client`.

The product profile stores the background status interval under the `codexy-ui-memory` entry.
