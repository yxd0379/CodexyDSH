# @codexydsh/ui-deliverables

Provides inline file references, deliverable cards, previews, native-open actions, and changed-file summaries. Its Host entry serves authenticated file routes and contributes model-visible file-reference guidance.

Enable this product plugin instead of the corresponding stock UI plugin. The fixed DSH 0.2.1-alpha.2 connection, Session, locale, layout, and slot services remain the framework providers. Browser entries are discovered through `dsh.client`.
