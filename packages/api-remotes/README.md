# Product Remote assembly

`@codexydsh/api-remotes` selects Host events and browser RPC contributions for CodexyDSH. It keeps the fixed DSH Gateway, Session, workspace, settings, and plugin-management protocols. The browser assembly mounts the owned permissions and delegation descriptors once; UI consumers do not mount those endpoints separately.

The contribution assembly follows the MIT-licensed DSH 0.2.1-alpha.2 entry point and imports its public packages. Approval waterfalls use `codexy-approval/request`; Session logs retain their required product facts through the runtime projection.
