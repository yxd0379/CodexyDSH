# @codexydsh/ui-permission-presets

Provides the current-session permission picker and the default permission row for future conversations. It consumes the owned process catalog and the upstream Session permissions projection; selections use the Host `/permission` command.

Enable this product plugin instead of the corresponding stock UI plugin. The fixed DSH 0.2.1-alpha.2 connection, Session, locale, layout, and slot services remain the framework providers. Browser entries are discovered through `dsh.client`.
