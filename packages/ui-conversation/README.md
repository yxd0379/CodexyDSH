# @codexydsh/ui-conversation

Owns the composer, input state machine, event assembly, queued submissions, image references, group registry, request inspection, and conversation preferences. A projected event feed expands durable product facts while preserving upstream sequence numbers and subscription lifetime.

Enable this product plugin instead of the corresponding stock UI plugin. The fixed DSH 0.2.1-alpha.2 connection, Session, locale, layout, and slot services remain the framework providers. Browser entries are discovered through `dsh.client`.

The product profile stores the busy-Enter preference under the `codexy-ui-conversation` entry.
