# 远端工作区界面

原生侧栏接纳按主机区分的工作区来源。选择远端会话时，显示该主机持久保留的同源原生 Web Client；它原有的会话、上传、文件浏览、终端、审批和对话服务保持在一起，远端会话 ID 不进入本机 Controller。切回本机工作区只隐藏远端文档，不销毁草稿或终端。

SSH 主机设置管理连接、交互式 SSH 认证、远端网络代理和连接日志。现有目录浏览器列出本机和已连接远端；选择远端目录只会在对应主机创建工作区。本机和远端工作区在原生“设置 → 工作区”中统一管理显示与属性；归档工作区只隐藏行，不删除会话或文件，会话归档仍由对应主机独立管理。

主机列表通过 Gateway 已有的逻辑流跟随连接恢复，重连后重新接收完整列表。保存主机不需要先连上 SSH；暂时的传输重建不会终止列表更新，也不会作为 SSH 连接失败显示。

应用 Loader 在各主机组合相同的原生 Client，本插件不另建功能插件名单，也不交换全局 transport。Web 入口提供子文档自己的 Desktop socket 地址，浏览器持久化按文档部署目录区分。导航消息核验发送窗口、来源和文档身份后才执行。服务缓存与支持的平台见[远端服务部署](../../ssh/codexy-remote/README.md)。
