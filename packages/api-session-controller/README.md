# Product Session controller

The owned Host provider preserves the published DSH Session Remote endpoints and browser wire types, while Agent activation installs the product preparation-bound model selector and model catalogs use captured native provider metadata. Its Remote binding uses the published `sessionController` service key, and `codexySessionController` provides the same service to product consumers. The upstream provider row must be disabled.

Client transport and wire vocabulary remain supplied by the exact DSH dependency. The product Host metadata and Client Remote contribution replace the model-catalog result codec to retain `showInPicker`, `multiAgentVersion`, and `serviceTiers`; the product Remote assembly must mount this contribution once. No platform private fields are patched.

The product controller has no browser entry. The existing DSH Session client provides the object and lifecycle services required by both public and product UI plugins.
