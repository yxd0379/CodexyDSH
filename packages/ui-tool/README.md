# @codexydsh/ui-tool

Provides tool-call trees and cards for native Codex calls, shell output, files and diffs, searches, terminals, jobs, plans, images, and delegated agents. Cards derive from recorded calls and results so history does not depend on live tools.

Enable this product plugin instead of the corresponding stock UI plugin. The fixed DSH 0.2.1-alpha.2 connection, Session, locale, layout, and slot services remain the framework providers. Browser entries are discovered through `dsh.client`.
